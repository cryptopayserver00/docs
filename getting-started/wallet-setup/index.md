---
title: "Wallet Setup"
description: "Set the wallet needed when setting up shop payment."
---

After **account registration** and **store creation**, it's time to configure a wallet in your CryptoPay Server, so that you can start receiving payments into it.

There are two ways to set up a wallet in CryptoPay Server:

* **Connect an existing wallet**
* **Create a new wallet**

There are many options on how set up a wallet with your CryptoPay Server. It's up to you to decide what works best for you use-case. Once you configure a wallet, you're all set. The next step, is to **start exploring the features**.
