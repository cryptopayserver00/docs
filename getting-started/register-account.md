This page relates to registering an account on a CryptoPay Server instance of your own, or using a third-party host.

To register a demo account, visit the **official demo**.

To deploy an instance of your own, see **choosing a deployment method**.

A non-exhaustive list of third-party hosts can be found in the CryptoPay Server **directory**.

# Account Registration

The first step is setting up your CryptoPay Server is creating a user account. The first created account on a newly-deployed CryptoPay Server is automatically - admin.

To register, visit your CryptoPay Server URL and fill in the account registration from on the right. Input your password, password confirmation, e-mail and **third-party host**, you may be asked to verify your e-mail address to confirm the registration.

Once your account is successfully created, you'll be redirected to a new page where you can set up your store. you'll need to provide a store name, select the default currency, and choose a currency rate provider.

Congratulations! You've completed the first step: creating your account and store on CryptoPay Server.

Next Step: - **Connecting a Wallet**.

If you need to manage multiple stores on your server instance, refer to **Creating a store** for detailed instructions.

## Configuring e-mail

It's recommended that server admins **configure SMTP settings**. E-mail setup enables easier password reset for the instance uses in case forgotten credentials.

## Two-factor authentication

For further enhancing security and protecting account, it's recommended to enable two-factor authentication (both 2FA and U2F are supported). To enable 2FA or U2F, click on the user settings icon in the header menu.
